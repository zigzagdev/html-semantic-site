# Vancouver Tech Meetup Landing (Static)

架空のテックミートアップコミュニティを想定した、完全に静的なランディングサイトです。

本プロジェクトは  
**『HTML/CSS設計完全ガイド』（SB Creative）** を読んだあとのアウトプットとして作成しました。  
制約条件は明確で、**JavaScript・フレームワークは一切使用していません**。
またAI生成は以下の観点で使用しています。 
    - デザインの構成の壁打ちとしての相談
　　 - コンテンツアイデアのブレインストーミング
    - コードレビュー

目的は、**構造が整理されたHTMLと設計されたCSSだけで、どこまで実用的なサイトを作れるか**を示すことです。

---

- **JavaScriptに頼らずにHTML/CSS設計を実践すること**
- 設計や構造の判断を、他の開発者に説明できる状態にすること

本プロジェクトは、**フィクションではあるが、現実味を重視した設計**になっています。

---

## Pages

| Page | Description |
|------|-------------|
| `/index.html` | ヒーロー、イベント概要、タイムテーブル、スピーカー、会場情報 |
| `/contact.html` | 連絡先およびフォーム風UI（送信処理なし） |
| `/faq.html` | FAQ一覧ページ |

## Design Principles

### 1. No JavaScript
- すべての挙動は静的
- フォームはUIのみ
- 構造・可読性・レイアウトに集中するための制約

### 2. Semantic HTML
- `header` / `main` / `section` / `nav` / `footer` を適切に使用
- 見出し階層の正しさを重視
- アクセシビリティを意識したマークアップ

### 3. CSS Architecture
- BEM命名規則を採用

## Deployment

GitHub Pages など、任意の静的ホスティングサービスにそのままデプロイ可能です。
