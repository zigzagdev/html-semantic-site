# Vancouver Tech Meetup Landing (Static)

バンクーバーの架空のテックミートアップコミュニティを想定した、完全に静的なランディングサイトです。

本プロジェクトは  
**『HTML/CSS設計完全ガイド』（SB Creative）** を読んだあとのアウトプットとして作成しました。  
制約条件は明確で、**JavaScript・フレームワークは一切使用していません**。
またAI生成もコーディングで参照するにあたっては、使用していません。(壁打ちとしての相談はしています。)

目的は、**構造が整理されたHTMLと設計されたCSSだけで、どこまで実用的なサイトを作れるか**を示すことです。

---

- 明確なCTAによってミートアップ参加者を増やすこと
- 実運用を想定した、現実的で破綻のない情報構成を作ること
- **JavaScriptに頼らずにHTML/CSS設計を実践すること**
- 設計や構造の判断を、他の開発者に説明できる状態にすること

本プロジェクトは、**フィクションではあるが、現実味を重視した設計**になっています。

---

## Pages

| Page | Description |
|------|-------------|
| `/index.html` | ヒーロー、イベント概要、タイムテーブル、スピーカー、会場概要、FAQ、CTA |
| `/venue.html` | 会場情報・アクセス（静的な地図画像） |
| `/contact.html` | 連絡先およびフォーム風UI（送信処理なし） |

## Design Principles

### 1. No JavaScript
- すべての挙動は静的
- フォームはUIのみ
- 構造・可読性・レイアウトに集中するための制約

### 2. Semantic HTML
- `header` / `main` / `section` / `nav` / `footer` を適切に使用
- 見出し階層の正しさを重視
- アクセシビリティを意識したマークアップ

### 3. CSS Architecture
- CSS変数で色・余白・タイポグラフィを管理
- BEM命名規則を採用

### 4. Mobile First
- 小さい画面を起点に設計
- 大きな画面には段階的に拡張

## Why Vancouver?

テーマとコンテンツは、バンクーバーのテックコミュニティを意識して設計しています。

- 小〜中規模のコミュニティイベント
- 分かりやすく実務的な情報設計
